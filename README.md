# 💰 Personal Finance Tracker

Full-stack aplikacija za praćenje ličnih finansija — prihodi, rashodi, kategorije, statistika.

## Tech Stack

**Backend:** Node.js, Express 5, JWT (bcrypt + jsonwebtoken), Zod 4  
**Frontend:** Next.js (App Router), React Hook Form, Recharts, Tailwind CSS  
**Deploy:** Railway (backend) + Vercel (frontend)
